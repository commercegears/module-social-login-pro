# Changelog

## 1.0.3 (2026-10-11)
- Button labels accept plain text only (up to 60 characters); sort orders must be whole numbers from 0 to 9999.
- Apple Team ID and Key ID must be 10 letters and digits.
- Requires Softaware Core 1.3, which checks these settings on the server when they are saved.
- Product page: no live demo links until the demo store runs Social Login Pro.

## 1.0.2 (2026-10-09)
- Docs: no dashes as punctuation in headings and version ranges.

## 1.0.1 (2026-10-09)
- Microsoft setup hint and docs use the current Microsoft Entra admin centre names.
- Docs link to softawarecommerce.com; doc screenshots retaken.

## 1.0.0 (2026-10-07)
- First release: Apple, Microsoft, LinkedIn, Amazon and GitHub sign-in for Softaware Social Login 1.3+.
- ID tokens validated against each provider's keys; PKCE where supported; Apple client secret made per request.
- Settings, button icons (Luma and Hyvä), setup hints and self-test checks for the five providers.
